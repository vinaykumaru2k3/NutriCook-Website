## 🌟 About NutriCook - A Health Revolution

### **Our Mission: Healthier Families, Healthier India**

NutriCook is pioneering a **health revolution** in Indian kitchens by introducing **surgical-grade 316L steel cookware** that eliminates the need for oil and water in cooking. Our innovative **Accuthermal Technology** preserves 100% of food's natural nutrients while enhancing authentic flavors.

### **The Health Impact**

🏥 **Medical-Grade Safety**: Using the same surgical steel found in medical implants  
🫀 **Heart Health**: Eliminates harmful trans fats and excess oils from daily cooking  
🥗 **Nutrient Preservation**: Retains 95% more vitamins and minerals compared to traditional cooking  
👨‍👩‍👧‍👦 **Family Wellness**: Protecting 50,000+ families across India from lifestyle diseases  
🌍 **Environmental Impact**: Reducing oil consumption by 80% and gas usage by 50%

### **Why This Matters**

In a country where **diabetes affects 77 million people** and **heart disease is the leading cause of death**, NutriCook offers a practical solution that transforms everyday cooking into a health-promoting activity. Every meal becomes an investment in your family's long-term wellness.

### **The Technology Behind Health**

- **🔬 Surgical Grade 316L Steel**: The purest form of steel, used in medical implants
- **⚡ Accuthermal Technology**: Even heat distribution without oil or water
- **🛡️ 30-Year Guarantee**: Built to last generations, not seasons
- **🌡️ Temperature Control**: Precise cooking that preserves nutrients
- **💧 Waterless Cooking**: Retains natural moisture and flavors

## 🚀 Quick Start for Developers

### **Prerequisites**

- Node.js 18+ and npm 9+
- Understanding of React and modern web development
- Passion for creating health-focused digital experiences

### **Installation & Setup**

```bash
# Clone this health-tech repository
git clone <repository-url>
cd nutricook-website

# Install dependencies
npm install

# Start development server
npm run dev
# Visit http://localhost:5173 to see the health revolution in action

# Build for production with health-focused optimizations
npm run build:verify

# Preview the production build
npm run preview
```
